## Nasıl Kullanılır

**Eğitime katıldıysanız:** Modülleri sırayla okuyun. Her modül eğitimde anlattıklarımızın yazılı versiyonu + eğitimde söylemediğim şeyler.

**Kendi başınıza geliyorsanız:** `docs/crash-course.md` ile başlayın. Oradan modüllere geçin.

**Belirli bir şeye bakıyorsanız:** `examples/` klasörü doğrudan kullanılabilir. Her dosya kendi kendine açıklayıcı.

## Repo Felsefesi

Bu repo şu üç şeyi yapmaz:
- Araç tanıtımı (ChatGPT vs Claude vs Gemini tartışması yok)
- "10 prompt hilesi" listeleri

Bunun yerine şunlara odaklanır:
- Prensipler — araçlar değişir, prensipler kalmaz
- Gerçek kullanım — kurumsal, akademik, yaratıcı bağlamlar
- Dürüst sınırlar — ne işe yaramaz, nerede kırılır
